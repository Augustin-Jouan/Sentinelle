# Sentinelle Marchés — Planning : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer l'onglet Planning (Gantt interactif à parité avec la maquette, fermetures, couleurs), le planning prévisionnel imprimé sur une seule feuille et la feuille de visa rattachée à une version du planning, figés et versionnés.

**Architecture:** Les règles du planning (semaines ISO, cascade, boucles, étendue) vivent une seule fois dans `src/domaine/` et servent au navigateur (affichage immédiat d'un geste) comme au serveur (ce qui est enregistré). Chaque geste devient une Server Action qui porte une intention, appliquée sous verrou du chantier au planning relu en base, et renvoie le planning complet. Les deux documents suivent la chaîne du Socle (objet JSON → gabarit React sans hook → Playwright) ; une fonction DOM unique, `ajusterUneFeuille`, fait tenir la feuille sur une page dans l'aperçu comme dans le PDF.

**Tech Stack:** celle du Socle — Next.js 16.3.7, React 19, TypeScript strict, Tailwind 4 + shadcn/ui (Base UI), Prisma 7.10.0, PostgreSQL 17, Zod 4, Playwright 1.63.0, Vitest 5, pdf-lib (tests). Aucune dépendance nouvelle.

**Spec:** `docs/superpowers/specs/2026-09-29-planning-design.md` — à lire avant toute tâche, avec la spec du Socle (`docs/superpowers/specs/2026-09-29-socle-design.md`). Maquette de référence : `docs/maquette/sentinelle-marches.html`.

**Prérequis :** le plan du Socle (`docs/superpowers/plans/2026-09-29-socle.md`) est entièrement exécuté et `npm test`, `npm run test:int` et `npm run test:e2e` passent. Les extraits du code du Socle cités ici (`generer.ts`, `etats.ts`, `ApercuDocument.tsx`, `TableauDocuments.tsx`…) viennent de son plan : si le code livré diffère sur un détail (nom d'une variable locale, ordre des champs), appliquer la même modification au code réel.

## Global Constraints

- Tout en français : interface, fichiers, variables, fonctions, commentaires, messages. Exceptions imposées par les outils (champs Better Auth, `'admin' | 'user'`).
- Les gabarits de `src/documents/gabarits/` n'ont ni `'use client'`, ni hook, ni contexte React ; ils ne calculent ni ne formatent rien : tous les textes viennent de l'objet document. Réunir texte fixe et valeur dans une chaîne de gabarit (`{`… ${x}`}`) pour éviter les `<!-- -->` dans le HTML.
- Seul `{ type, contenu }` entre dans l'empreinte ; le `cadre` (en-tête SOCOREVE, date de génération) en est exclu.
- Une Server Action renvoie toujours `Resultat<T>` et ne lève jamais d'exception jusqu'à l'interface (enveloppe `executer` du Socle).
- Aucun journal ne contient de HTML, de montant ni de nom de client.
- Planning et visa : A4 paysage, marges 10 mm, **toujours une seule page** ; échelle minimale 0,4, au-delà « Trop de lots pour une seule feuille. ».
- Semaines ISO 8601 ; `Periode.debut` et `Fermeture.debut` sont des **lundis** (`DATE`, contrainte `CHECK` en base) ; durée d'une période 1 à 104 semaines, d'une fermeture 1 à 52 ; années 2000 à 2100.
- Toute écriture du planning passe par `sousVerrou` (`SELECT … FOR UPDATE` sur la ligne du chantier, relecture, opération du domaine, écriture des seules lignes changées, relecture) et renvoie le planning complet.
- Les règles du planning n'existent qu'une fois, dans `src/domaine/planning.ts` : ni le composant ni `src/donnees/` ne recodent la cascade.
- Jamais `prisma migrate reset` ni `prisma migrate dev` : une migration s'écrit à la main ou avec `prisma migrate diff … --script`, s'applique avec `prisma migrate deploy` et se vérifie avec `prisma migrate diff --from-config-datasource --to-schema prisma/schema.prisma --exit-code` (0 = aucun écart). Essai réalisé avec Prisma 7.10 : ce contrôle ignore les `CHECK` écrits à la main et les valeurs d'enum s'ajoutent sans erreur pendant `migrate deploy`.
- Préférences d'affichage (outil, densité, lots masqués) : `localStorage`, chaque lecture et écriture dans un `try/catch`, l'écran fonctionnant sans.
- Liens stylés en bouton : `className={buttonVariants({ … })}` sur `<Link>` (le `Button` du projet est celui de Base UI, sans `asChild`).

```ts
/** Semaines ISO 8601 : le lundi ouvre la semaine, la semaine 1 contient le premier jeudi de l'année. Dates à minuit UTC. */

const MS_JOUR = 86_400_000;
export const MS_SEMAINE = 7 * MS_JOUR;
/** Lundi 5 janvier 1970 : origine des rangs de semaine. */
const ORIGINE = Date.UTC(1970, 0, 5);

export const MOIS_ABREGES = ['janv.', 'févr.', 'mars', 'avr.', 'mai', 'juin', 'juil.', 'août', 'sept.', 'oct.', 'nov.', 'déc.'] as const;

export type Semaine = { annee: number; semaine: number };

const minuitUtc = (d: Date) => Date.UTC(d.getUTCFullYear(), d.getUTCMonth(), d.getUTCDate());

/** Lundi (minuit UTC) de la semaine ISO donnée. Ne vérifie pas que la semaine existe : voir `semaineExiste`. */
export function lundiIso(annee: number, semaine: number): Date {
	const quatreJanvier = Date.UTC(annee, 0, 4);
	const jour = new Date(quatreJanvier).getUTCDay() || 7;
	return new Date(quatreJanvier - (jour - 1) * MS_JOUR + (semaine - 1) * MS_SEMAINE);
}

export function semaineIso(d: Date): Semaine {
	const jour = minuitUtc(d);
	const n = new Date(jour).getUTCDay() || 7;
	// Le jeudi de la même semaine porte l'année ISO.
	const jeudi = new Date(jour + (4 - n) * MS_JOUR);
	const annee = jeudi.getUTCFullYear();
	return { annee, semaine: Math.floor((jeudi.getTime() - Date.UTC(annee, 0, 1)) / MS_SEMAINE) + 1 };
}

/** 52 ou 53 : le 28 décembre est toujours dans la dernière semaine de l'année. */
export function nombreSemaines(annee: number): number {
	return semaineIso(new Date(Date.UTC(annee, 11, 28))).semaine;
}

export function semaineExiste(annee: number, semaine: number): boolean {
	return Number.isInteger(annee) && Number.isInteger(semaine) && semaine >= 1 && semaine <= nombreSemaines(annee);
}

/** Rang absolu de la semaine d'une date : deux rangs consécutifs sont deux semaines consécutives, Nouvel An compris. */
export const rangDe = (d: Date): number => Math.floor((minuitUtc(d) - ORIGINE) / MS_SEMAINE);
export const lundiDuRang = (rang: number): Date => new Date(ORIGINE + rang * MS_SEMAINE);
export const rangSemaine = (annee: number, semaine: number): number => rangDe(lundiIso(annee, semaine));
export const semaineDuRang = (rang: number): Semaine => semaineIso(lundiDuRang(rang));
export const lundiDe = (d: Date): Date => lundiDuRang(rangDe(d));

export const versIso = (d: Date): string => d.toISOString().slice(0, 10);
export const depuisIso = (s: string): Date => new Date(`${s}T00:00:00Z`);

/** « avr.-26 » : le mois du lundi de la semaine, comme le .ods d'origine. */
export function libelleMois(rang: number): string {
	const lundi = lundiDuRang(rang);
	return `${MOIS_ABREGES[lundi.getUTCMonth()]}-${String(lundi.getUTCFullYear()).slice(2)}`;
}

const FORMAT_PARIS = new Intl.DateTimeFormat('en-CA', { timeZone: 'Europe/Paris', year: 'numeric', month: '2-digit', day: '2-digit' });

/** Le jour calendaire à Châteaubriant, en minuit UTC. */
export const dateParis = (maintenant: Date): Date => depuisIso(FORMAT_PARIS.format(maintenant));
```

```ts
import { ErreurMetier } from './erreurs';
import { libelleMois, lundiDuRang, nombreSemaines, rangSemaine, semaineDuRang } from './semaines';

/** Toutes les positions sont des rangs de semaine (voir semaines.ts). */
export type Plage = { debut: number; duree: number };
export type PeriodePlan = Plage & { id: string; lotId: string; intitule: string; dependDeId: string | null };
/** `decalees` : périodes déplacées par la cascade, hors celles que l'opération visait. */
export type ResultatPlan = { periodes: PeriodePlan[]; decalees: number };
export type Etendue = { debut: number; fin: number; nb: number };
export type Colonne = { rang: number; semaine: number; annee: number };

export const DUREE_MAX = 104;
export const RANG_MIN = rangSemaine(2000, 1);
export const RANG_MAX = rangSemaine(2100, nombreSemaines(2100));

const PERIODE_DISPARUE = "Cette période n'existe plus.";

export const finPeriode = (p: Plage): number => p.debut + p.duree - 1;

function trouver(periodes: PeriodePlan[], id: string): PeriodePlan {
	const p = periodes.find((x) => x.id === id);
	if (!p) throw new ErreurMetier(PERIODE_DISPARUE);
	return p;
}

const copier = (periodes: PeriodePlan[]) => periodes.map((p) => ({ ...p }));

export function verifierDuree(duree: number): void {
	if (!Number.isInteger(duree) || duree < 1 || duree > DUREE_MAX) {
		throw new ErreurMetier(`La durée doit être comprise entre 1 et ${DUREE_MAX} semaines.`);
	}
}

/** Vrai si `candidat` est `id` ou en dépend, directement ou non. */
export function dependDe(periodes: PeriodePlan[], candidat: string, id: string): boolean {
	const index = new Map(periodes.map((p) => [p.id, p]));
	let courant: string | null = candidat;
	for (let pas = 0; courant && pas <= periodes.length; pas++) {
		if (courant === id) return true;
		courant = index.get(courant)?.dependDeId ?? null;
	}
	return false;
}

/** Profondeur de chaque période dans sa chaîne (0 = sans amont) : l'amont passe toujours avant ses suites. */
function profondeurs(periodes: PeriodePlan[]): Map<string, number> {
	const index = new Map(periodes.map((p) => [p.id, p]));
	const prof = new Map<string, number>();
	for (const depart of periodes) {
		const chaine: PeriodePlan[] = [];
		let p: PeriodePlan | undefined = depart;
		while (p && !prof.has(p.id)) {
			if (chaine.includes(p)) throw new Error('Boucle de dépendances dans le planning.');
			chaine.push(p);
			p = p.dependDeId ? index.get(p.dependDeId) : undefined;
		}
		let niveau = p ? prof.get(p.id)! + 1 : 0;
		for (let i = chaine.length - 1; i >= 0; i--) prof.set(chaine[i].id, niveau++);
	}
	return prof;
}

/**
 * Applique la contrainte fin → début à tout le planning, amont d'abord : une période liée commence
 * au plus tôt la semaine qui suit la fin de son amont. Ne recule jamais une période.
 * Le résultat ne dépend donc pas de l'ordre dans lequel on a modifié les périodes.
 */
export function contraindre(periodes: PeriodePlan[], visees: ReadonlySet<string> = new Set()): ResultatPlan {
	const avant = new Map(periodes.map((p) => [p.id, p.debut]));
	const resultat = copier(periodes);
	const index = new Map(resultat.map((p) => [p.id, p]));
	const prof = profondeurs(resultat);
	for (const p of [...resultat].sort((a, b) => prof.get(a.id)! - prof.get(b.id)!)) {
		const amont = p.dependDeId ? index.get(p.dependDeId) : undefined;
		if (amont && p.debut <= finPeriode(amont)) p.debut = finPeriode(amont) + 1;
	}
	for (const p of resultat) {
		if (p.debut < RANG_MIN) throw new ErreurMetier('Les périodes ne peuvent pas commencer avant 2000.');
		if (finPeriode(p) > RANG_MAX) throw new ErreurMetier('Ce déplacement pousserait des périodes au-delà de 2100.');
	}
	const decalees = resultat.filter((p) => !visees.has(p.id) && avant.get(p.id) !== p.debut).length;
	return { periodes: resultat, decalees };
}

export function creerPeriode(periodes: PeriodePlan[], nouvelle: PeriodePlan): ResultatPlan {
	verifierDuree(nouvelle.duree);
	return contraindre([...periodes, nouvelle], new Set([nouvelle.id]));
}

export function deplacerPeriodes(periodes: PeriodePlan[], mouvements: { id: string; debut: number }[]): ResultatPlan {
	const copie = copier(periodes);
	for (const m of mouvements) trouver(copie, m.id).debut = m.debut;
	return contraindre(copie, new Set(mouvements.map((m) => m.id)));
}

export function decalerPeriodes(periodes: PeriodePlan[], ids: string[], semaines: number): ResultatPlan {
	return deplacerPeriodes(periodes, ids.map((id) => ({ id, debut: trouver(periodes, id).debut + semaines })));
}

export function modifierPeriode(
	periodes: PeriodePlan[], id: string, changement: { debut?: number; duree?: number; intitule?: string },
): ResultatPlan {
	if (changement.duree !== undefined) verifierDuree(changement.duree);
	const copie = copier(periodes);
	Object.assign(trouver(copie, id), changement);
	return contraindre(copie, new Set([id]));
}

export function lierPeriode(periodes: PeriodePlan[], id: string, dependDeId: string | null): ResultatPlan {
	const copie = copier(periodes);
	const p = trouver(copie, id);
	if (dependDeId !== null) {
		const amont = trouver(copie, dependDeId);
		if (dependDe(copie, dependDeId, id)) {
			throw new ErreurMetier(`Ce lien créerait une boucle : ${amont.intitule || 'la période choisie'} dépend déjà de cette période.`);
		}
	}
	p.dependDeId = dependDeId;
	return contraindre(copie, new Set([id]));
}

/** Les périodes déjà absentes sont ignorées ; les suites des périodes supprimées sont détachées sans bouger. */
export function supprimerPeriodes(periodes: PeriodePlan[], ids: string[]): ResultatPlan {
	const retirees = new Set(ids);
	return {
		periodes: periodes
			.filter((p) => !retirees.has(p.id))
			.map((p) => ({ ...p, dependDeId: p.dependDeId && retirees.has(p.dependDeId) ? null : p.dependDeId })),
		decalees: 0,
	};
}

/** Amonts possibles d'une période : ni elle-même, ni ce qui dépend d'elle. */
export function optionsDependance(periodes: PeriodePlan[], id: string): PeriodePlan[] {
	return periodes.filter((p) => p.id !== id && !dependDe(periodes, p.id, id));
}

const moisDuRang = (rang: number) => lundiDuRang(rang).getUTCMonth();

/** De la première à la dernière semaine couverte, élargie pour ne jamais couper un mois (règle `etendue` de la maquette). */
export function etendue(plages: Plage[], rangParDefaut: number): Etendue {
	let debut = rangParDefaut;
	let fin = rangParDefaut + 51;
	if (plages.length) {
		debut = Math.min(...plages.map((p) => p.debut));
		fin = Math.max(...plages.map(finPeriode));
	}
	for (let garde = 0; garde < 6 && moisDuRang(debut - 1) === moisDuRang(debut); garde++) debut--;
	for (let garde = 0; garde < 6 && moisDuRang(fin + 1) === moisDuRang(fin); garde++) fin++;
	return { debut, fin, nb: fin - debut + 1 };
}

/** De la première semaine de la première période à la dernière semaine de la dernière ; sans les fermetures. */
export function periodeTravaux(plages: Plage[]): { debut: number; fin: number } | null {
	if (!plages.length) return null;
	return { debut: Math.min(...plages.map((p) => p.debut)), fin: Math.max(...plages.map(finPeriode)) };
}

export function colonnes(e: Etendue): Colonne[] {
	return Array.from({ length: e.nb }, (_, i) => {
		const s = semaineDuRang(e.debut + i);
		return { rang: e.debut + i, semaine: s.semaine, annee: s.annee };
	});
}

export function moisDesColonnes(cols: Colonne[]): { libelle: string; nb: number }[] {
	const mois: { libelle: string; nb: number }[] = [];
	for (const c of cols) {
		const libelle = libelleMois(c.rang);
		const dernier = mois[mois.length - 1];
		if (dernier?.libelle === libelle) dernier.nb++;
		else mois.push({ libelle, nb: 1 });
	}
	return mois;
}

export function messageSuites(n: number): string | undefined {
	if (!n) return undefined;
	return n > 1 ? `${n} périodes décalées à la suite.` : '1 période décalée à la suite.';
}

export function messageGroupe(nombre: number, delta: number, suites: number): string {
	const semaines = `${Math.abs(delta)} semaine${Math.abs(delta) > 1 ? 's' : ''}`;
	return `${nombre} périodes décalées de ${semaines} ${delta < 0 ? 'plus tôt' : 'plus tard'}${suites ? ` — ${suites} à la suite` : ''}.`;
}
```

```ts
import { etendue, type Etendue, type PeriodePlan, type Plage } from './planning';
import { depuisIso, lundiDuRang, rangDe, versIso } from './semaines';

/** Forme du planning échangée entre le serveur et l'écran : dates en `AAAA-MM-JJ` (lundis). */
export type PeriodeVue = { id: string; intitule: string; debut: string; duree: number; dependDeId: string | null };
export type LotPlanning = {
	id: string; numero: string | null; designation: string; entreprise: string | null; telephone: string | null;
	couleur: string; periodes: PeriodeVue[];
};
export type FermetureVue = { id: string; libelle: string; debut: string; duree: number };
export type PlanningVue = { chantierId: string; dateSignaturePrevue: string | null; lots: LotPlanning[]; fermetures: FermetureVue[] };
export type ReponsePlanning = { planning: PlanningVue; message?: string; periodeId?: string };

/** Rang de la semaine d'une date `AAAA-MM-JJ` (un jour quelconque donne le rang de son lundi). */
export const rangIso = (iso: string): number => rangDe(depuisIso(iso));
export const isoRang = (rang: number): string => versIso(lundiDuRang(rang));

export function periodesDuPlanning(vue: PlanningVue): PeriodePlan[] {
	return vue.lots.flatMap((l) => l.periodes.map((p) => ({
		id: p.id, lotId: l.id, intitule: p.intitule, debut: rangIso(p.debut), duree: p.duree, dependDeId: p.dependDeId,
	})));
}

/** Replace des périodes calculées dans la vue : triées par début, l'ordre d'origine départageant les égalités. */
export function appliquerPeriodes(vue: PlanningVue, periodes: PeriodePlan[]): PlanningVue {
	const parLot = new Map<string, PeriodePlan[]>();
	for (const p of periodes) parLot.set(p.lotId, [...(parLot.get(p.lotId) ?? []), p]);
	return {
		...vue,
		lots: vue.lots.map((l) => ({
			...l,
			periodes: (parLot.get(l.id) ?? [])
				.map((p, i) => ({ p, i }))
				.sort((a, b) => a.p.debut - b.p.debut || a.i - b.i)
				.map(({ p }) => ({ id: p.id, intitule: p.intitule, debut: isoRang(p.debut), duree: p.duree, dependDeId: p.dependDeId })),
		})),
	};
}

export const plagesFermetures = (vue: PlanningVue): Plage[] => vue.fermetures.map((f) => ({ debut: rangIso(f.debut), duree: f.duree }));

/** Sans période : la date de signature prévue, sinon le jour donné. */
export const rangParDefaut = (vue: PlanningVue, aujourdhui: string): number => rangIso(vue.dateSignaturePrevue ?? aujourdhui);

export const etendueDuPlanning = (vue: PlanningVue, aujourdhui: string): Etendue =>
	etendue([...periodesDuPlanning(vue), ...plagesFermetures(vue)], rangParDefaut(vue, aujourdhui));
```

```ts
export async function insererPlanningPerrier(p: { chantierId: string; lots: Record<string, string> }) {
	const periodes: Record<string, string> = {};
	for (const ligne of PLAN_PERRIER) {
		const lotId = p.lots[ligne.lot];
		await prisma.lot.update({ where: { id: lotId }, data: { couleur: ligne.couleur } });

			periodes[x.intitule] = cree.id;
		}
	}
	for (let i = 1; i < CHAINE_PERRIER.length; i++) {
		await prisma.periode.update({ where: { id: periodes[CHAINE_PERRIER[i]] }, data: { dependDeId: periodes[CHAINE_PERRIER[i - 1]] } });
	}
	const fermetures: string[] = [];

		fermetures.push(cree.id);
```

```ts
export type ChampPeriode = 'intitule' | 'semaine' | 'annee' | 'duree';
export type ChampFermeture = 'libelle' | 'semaine' | 'annee' | 'duree';

const INTROUVABLE = 'Élément introuvable.';

async function lire(db: Pick<Tx, 'chantier'>, chantierId: string): Promise<PlanningVue | null> {
	const c = await db.chantier.findUnique({
		where: { id: chantierId },
		select: {
			id: true,
			dateSignaturePrevue: true,
			lots: {
				orderBy: { ordre: 'asc' },
				select: {
					id: true, numero: true, designation: true, couleur: true,
					artisan: { select: { nom: true, telephone: true } },
					periodes: {
						orderBy: [{ debut: 'asc' }, { creeLe: 'asc' }],
						select: { id: true, intitule: true, debut: true, duree: true, dependDeId: true },
					},
				},
			},
			fermetures: { orderBy: [{ debut: 'asc' }, { id: 'asc' }], select: { id: true, libelle: true, debut: true, duree: true } },
		},
	});
	if (!c) return null;
	return {
		chantierId: c.id,
		dateSignaturePrevue: c.dateSignaturePrevue ? versIso(c.dateSignaturePrevue) : null,
		lots: c.lots.map((l) => ({
			id: l.id, numero: l.numero, designation: l.designation, couleur: l.couleur,
			entreprise: l.artisan?.nom ?? null,
			telephone: l.artisan?.telephone || null,
			periodes: l.periodes.map((x) => ({ ...x, debut: versIso(x.debut) })),
		})),
		fermetures: c.fermetures.map((f) => ({ ...f, debut: versIso(f.debut) })),
	};
}

export function lirePlanning(chantierId: string): Promise<PlanningVue | null> {
	return lire(prisma, chantierId);
}

/**
 * Verrou du chantier, relecture, opération, relecture. L'opération s'applique au planning de la base,
 * jamais à celui que le navigateur avait sous les yeux : deux gestes sur des périodes différentes sont conservés.
 */
async function sousVerrou(chantierId: string, operation: (tx: Tx, vue: PlanningVue) => Promise<Suite>): Promise<ReponsePlanning> {
	return prisma.$transaction(async (tx) => {
		const verrou = await tx.$queryRaw<{ id: string }[]>`SELECT id FROM "Chantier" WHERE id = ${chantierId} FOR UPDATE`;
		if (!verrou.length) throw new ErreurMetier(INTROUVABLE);
		const suite = (await operation(tx, (await lire(tx, chantierId))!)) ?? {};
		return { planning: (await lire(tx, chantierId))!, ...suite };
	});
}

/** N'écrit que les périodes qui ont changé. */
async function ecrirePeriodes(tx: Tx, avant: regles.PeriodePlan[], apres: regles.PeriodePlan[]) {
	const anciennes = new Map(avant.map((x) => [x.id, x]));
	for (const x of apres) {
		const a = anciennes.get(x.id);
		const donnees = { intitule: x.intitule, debut: lundiDuRang(x.debut), duree: x.duree, dependDeId: x.dependDeId };
		if (!a) {
			await tx.periode.create({ data: { id: x.id, lotId: x.lotId, ...donnees } });
		} else if (a.intitule !== x.intitule || a.debut !== x.debut || a.duree !== x.duree || a.dependDeId !== x.dependDeId) {
			await tx.periode.update({ where: { id: x.id }, data: donnees });
		}
	}
	const restantes = new Set(apres.map((x) => x.id));
	const supprimees = avant.filter((x) => !restantes.has(x.id)).map((x) => x.id);
	if (supprimees.length) await tx.periode.deleteMany({ where: { id: { in: supprimees } } });
}

/** Chaque id doit être une période du chantier : sinon « Élément introuvable. » (autre chantier) ou « n'existe plus ». */
async function verifierPeriodes(tx: Tx, periodes: regles.PeriodePlan[], ids: string[], ignorerDisparues = false) {
	const connues = new Set(periodes.map((x) => x.id));
	for (const id of ids) {
		if (connues.has(id)) continue;
		if (await tx.periode.findUnique({ where: { id }, select: { id: true } })) throw new ErreurMetier(INTROUVABLE);
		if (!ignorerDisparues) throw new ErreurMetier(PERIODE_DISPARUE);
	}
}

async function chantierDuLot(lotId: string): Promise<string> {
	const lot = await prisma.lot.findUnique({ where: { id: lotId }, select: { chantierId: true } });
	if (!lot) throw new ErreurMetier(LOT_DISPARU);
	return lot.chantierId;
}

/** Nombre entier saisi dans un champ ; tout le reste (vide, lettres, décimales) est refusé. */
function entier(valeur: string, message: string, champ: string): number {
	const t = valeur.trim();
	if (!/^\d{1,6}$/.test(t)) throw new ErreurMetier(message, champ);
	return Number(t);
}

/** Une semaine 53 qui n'existe pas est refusée, jamais recalée sur la semaine 1 suivante. */
function rangSaisi(annee: number, semaine: number): number {
	if (annee < 2000 || annee > 2100) throw new ErreurMetier("L'année doit être comprise entre 2000 et 2100.", 'annee');
	if (!semaineExiste(annee, semaine)) throw new ErreurMetier("Cette semaine n'existe pas.", 'semaine');
	return rangSemaine(annee, semaine);
}

/** Nouveau début quand on change la semaine ou l'année d'un début existant. */
function debutSaisi(debut: number, champ: 'semaine' | 'annee', valeur: string): number {
	const s = semaineDuRang(debut);
	return champ === 'annee'
		? rangSaisi(entier(valeur, 'Année : saisissez un nombre entier.', 'annee'), s.semaine)
		: rangSaisi(s.annee, entier(valeur, 'Semaine : saisissez un nombre entier.', 'semaine'));
}

function changementPeriode(x: regles.PeriodePlan, champ: ChampPeriode, valeur: string): { debut?: number; duree?: number; intitule?: string } {
	if (champ === 'intitule') {
		const intitule = valeur.trim();
		if (intitule.length > 120) throw new ErreurMetier("L'intitulé fait 120 caractères au plus.", 'intitule');
		return { intitule };
	}
	// La borne 1-104 est contrôlée par le domaine.
	if (champ === 'duree') return { duree: entier(valeur, 'Durée : saisissez un nombre entier.', 'duree') };
	return { debut: debutSaisi(x.debut, champ, valeur) };
}

export async function creerPeriode(lotId: string, debut: string, duree: number): Promise<ReponsePlanning> {
	return sousVerrou(await chantierDuLot(lotId), async (tx, vue) => {
		if (!vue.lots.some((l) => l.id === lotId)) throw new ErreurMetier(LOT_DISPARU);
		const avant = periodesDuPlanning(vue);
		const id = randomUUID();
		const rang = rangIso(debut);
		const res = regles.creerPeriode(avant, { id, lotId, intitule: '', debut: rang, duree, dependDeId: null });
		await ecrirePeriodes(tx, avant, res.periodes);
		return { message: `Période créée — semaine ${semaineDuRang(rang).semaine}, ${duree} sem. Nommez-la si besoin.`, periodeId: id };
	});
}

export async function deplacerPeriodes(chantierId: string, mouvements: { id: string; debut: string }[]): Promise<ReponsePlanning> {
	return sousVerrou(chantierId, async (tx, vue) => {
		const avant = periodesDuPlanning(vue);
		await verifierPeriodes(tx, avant, mouvements.map((m) => m.id));
		const vises = mouvements.map((m) => ({ id: m.id, debut: rangIso(m.debut) }));
		const res = regles.deplacerPeriodes(avant, vises);
		await ecrirePeriodes(tx, avant, res.periodes);
		const delta = vises[0].debut - avant.find((x) => x.id === vises[0].id)!.debut;
		if (vises.length > 1 && delta) return { message: regles.messageGroupe(vises.length, delta, res.decalees) };
		return { message: regles.messageSuites(res.decalees) };
	});
}

export async function modifierPeriode(id: string, champ: ChampPeriode, valeur: string): Promise<ReponsePlanning> {
	return sousVerrou(await chantierDeLaPeriode(id), async (tx, vue) => {
		const avant = periodesDuPlanning(vue);
		const x = avant.find((y) => y.id === id);
		if (!x) throw new ErreurMetier(PERIODE_DISPARUE);
		const res = regles.modifierPeriode(avant, id, changementPeriode(x, champ, valeur));
		await ecrirePeriodes(tx, avant, res.periodes);
		return { message: regles.messageSuites(res.decalees) };
	});
}

export async function lierPeriode(id: string, dependDeId: string | null): Promise<ReponsePlanning> {
	return sousVerrou(await chantierDeLaPeriode(id), async (tx, vue) => {
		const avant = periodesDuPlanning(vue);
		await verifierPeriodes(tx, avant, dependDeId ? [id, dependDeId] : [id]);
		const res = regles.lierPeriode(avant, id, dependDeId);
		await ecrirePeriodes(tx, avant, res.periodes);
		if (!dependDeId) return { message: 'Lien retiré — la période redevient libre.' };
		const suites = regles.messageSuites(res.decalees);
		return { message: suites ? `Lien posé. ${suites}` : 'Lien posé.' };
	});
}

export async function supprimerPeriodes(chantierId: string, ids: string[]): Promise<ReponsePlanning> {
	return sousVerrou(chantierId, async (tx, vue) => {
		const avant = periodesDuPlanning(vue);
		await verifierPeriodes(tx, avant, ids, true);
		const res = regles.supprimerPeriodes(avant, ids);
		await ecrirePeriodes(tx, avant, res.periodes);
		const n = avant.length - res.periodes.length;
		return { message: n > 1 ? `${n} périodes supprimées.` : n ? 'Période supprimée.' : undefined };
	});
}

function changementFermeture(debut: number, champ: ChampFermeture, valeur: string): { libelle?: string; debut?: Date; duree?: number } {
	if (champ === 'libelle') {
		const libelle = valeur.trim();
		if (libelle.length > 60) throw new ErreurMetier('Le libellé fait 60 caractères au plus.', 'libelle');
		return { libelle };
	}
	if (champ === 'duree') {
		const duree = entier(valeur, 'Durée : saisissez un nombre entier.', 'duree');
		if (duree < 1 || duree > 52) throw new ErreurMetier("La durée d'une fermeture doit être comprise entre 1 et 52 semaines.", 'duree');
		return { duree };
	}
	return { debut: lundiDuRang(debutSaisi(debut, champ, valeur)) };
}

}
```
